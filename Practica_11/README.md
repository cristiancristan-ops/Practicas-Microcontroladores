# Práctica 11 - PWM

## Descripción

En esta práctica se utilizó PWM para cambiar la intensidad de LEDs por medio de potenciómetros.

## Actividad 1 - Intensidad de un LED

Se conectó un potenciómetro para controlar el brillo de un LED.

Al mover el potenciómetro, el LED puede cambiar desde apagado hasta su intensidad máxima.

## Actividad 2 - Intensidad de dos LEDs

Se utilizaron dos potenciómetros y dos LEDs.

Cada potenciómetro controla la intensidad de un LED diferente, por lo que ambos pueden cambiar su brillo de manera independiente.

## Archivos incluidos

- Código para controlar dos LEDs con PWM.
