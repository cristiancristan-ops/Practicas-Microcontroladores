# Práctica 08 - Múltiple lectura analógica

## Descripción

En esta práctica se utilizaron dos potenciómetros conectados al PIC y una pantalla LCD para mostrar sus valores.

## Clase - Dos potenciómetros

Se leen dos entradas analógicas diferentes.

En la primera fila de la LCD se muestra el voltaje del primer potenciómetro y en la segunda fila se muestra el voltaje del segundo.

Los dos valores cambian de acuerdo con la posición de cada potenciómetro.

## Actividad 1 - Selección de lectura y vista

Se utilizaron botones para cambiar la información mostrada en la pantalla.

Un botón permite elegir entre el primer y el segundo potenciómetro. El otro botón cambia la vista entre:

- Voltaje.
- Porcentaje.
- Valor ADC.
