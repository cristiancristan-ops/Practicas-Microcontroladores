# Práctica 13 - Motor DC

## Descripción

En esta práctica se controló un motor de corriente directa utilizando un potenciómetro y diferentes circuitos de conexión.

## Actividad 1 - Control de velocidad con BJT

Se utilizó un transistor BJT para controlar la velocidad del motor.

El potenciómetro cambia la señal enviada al motor. Al moverlo, el motor aumenta o disminuye su velocidad.

## Actividad 2 - Velocidad y sentido con puente H

Se utilizó un puente H para controlar el motor.

El potenciómetro controla la velocidad y un botón cambia el sentido de giro. Cada vez que se presiona el botón, el motor gira en la dirección contraria.
