# Práctica 12 - Teclado matricial

## Descripción

En esta práctica se utilizó un teclado matricial de 4x4 junto con una pantalla LCD.

## Actividad 1 - Mostrar teclas en la LCD

Cada vez que se presiona una tecla, el carácter aparece en la pantalla LCD.

Al llenar la primera fila, el texto continúa en la segunda. Cuando se llena toda la pantalla, se limpia para comenzar nuevamente.

## Actividad 2 - Calculadora básica

Se realizó una calculadora sencilla utilizando el teclado y la LCD.

La calculadora puede realizar las siguientes operaciones:

- Suma.
- Resta.
- Multiplicación.
- División.

La tecla **C** limpia la operación y la tecla **=** muestra el resultado. Si se intenta dividir entre cero, aparece un mensaje de error.
