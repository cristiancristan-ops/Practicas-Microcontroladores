# Práctica 09 - Timer 0

## Descripción

En esta práctica se utilizó el Timer 0 del PIC para llevar un conteo de tiempo y mostrarlo en una pantalla LCD.

## Clase - Tiempo de ejecución

La pantalla muestra el tiempo que lleva funcionando el programa en formato de minutos y segundos.

El tiempo se actualiza automáticamente mientras el resto del programa continúa ejecutándose.

## Actividad 1 - Voltaje y tiempo

Se agregó un potenciómetro al circuito.

La LCD muestra al mismo tiempo:

- El voltaje leído del potenciómetro.
- El tiempo de ejecución del microcontrolador.
