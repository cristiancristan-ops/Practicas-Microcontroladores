# Práctica 07 - Lectura analógica

## Descripción

En esta práctica se utilizó un potenciómetro para obtener una lectura analógica y mostrarla en una pantalla LCD.

## Clase - Lectura de voltaje

El PIC lee la posición del potenciómetro y convierte el valor para mostrar el voltaje aproximado en la pantalla LCD.

Al mover el potenciómetro, el valor mostrado cambia.

## Actividad 1 - Cambio de vista

Se agregó un botón para cambiar la forma en la que se muestra la lectura del potenciómetro.

Las vistas disponibles son:

- Voltaje.
- Porcentaje.
- Valor ADC.

Cada vez que se presiona el botón, la pantalla cambia a la siguiente vista.
