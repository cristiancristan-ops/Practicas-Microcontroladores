# Práctica 06 - Display LCD 16x2

## Descripción

En esta práctica se utilizó una pantalla LCD de 16 columnas y 2 filas para mostrar texto y caracteres creados por nosotros.

## Clase - Hello World

En la primera parte se mostró el mensaje **HELLO WORLD!** en la primera fila de la pantalla.

En la segunda fila se escriben las letras del abecedario poco a poco para observar cómo se envían los caracteres a la LCD.

## Actividad 1 - Caracteres personalizados

Se crearon figuras especiales para mostrarlas en la pantalla LCD, entre ellas:

- Carritos.
- Corazones.
- Estrellas.

Con un botón se cambia entre diferentes pantallas. Una muestra el texto, otra muestra los carritos y otra muestra los símbolos personalizados.
