# Práctica 14 - Servomotores

## Descripción

En esta práctica se controló la posición de un servomotor utilizando el PIC16F887.

## Actividad 1 - Movimiento de 0° a 180°

El servomotor se mueve automáticamente desde 0° hasta 180°.

Al llegar al final, cambia de dirección y regresa a 0°. Este movimiento se repite continuamente.

## Actividad 2 - Control con potenciómetro

Se conectó un potenciómetro para controlar el ángulo del servomotor.

Al mover el potenciómetro, el servo cambia su posición de manera proporcional entre 0° y 180°.
