# Práctica 10 - Timer 1

## Descripción

En esta práctica se utilizó el Timer 1 para medir el tiempo de ejecución del programa y mostrarlo en una pantalla LCD.

## Clase - Tiempo de ejecución

La LCD muestra un contador de minutos y segundos que comienza desde 00:00.

El Timer 1 se encarga de actualizar el tiempo mientras el programa sigue funcionando.

## Actividad 1 - Voltaje y tiempo

Se conectó un potenciómetro para mostrar su voltaje en la pantalla.

La LCD presenta al mismo tiempo:

- El voltaje del potenciómetro.
- El tiempo de ejecución usando Timer 1.
